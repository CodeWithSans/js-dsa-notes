# JavaScript & DSA Notes

Revision notes for JavaScript fundamentals and data structures / algorithms,
written for interview prep.

Read online: https://codewithsans.github.io/js-dsa-notes/

Covers:

- JS essentials — array methods, the `.sort()` trap, Map/Set, string handling
- JS concepts — scope, hoisting, `==` vs `===`, closures, `this`, event loop, promises
- Complexity — Big-O, with where each one shows up
- Easy problems — Two Sum, palindrome, anagram, move zeroes, and more
- The four patterns — hash map, two pointers, sliding window, stack
